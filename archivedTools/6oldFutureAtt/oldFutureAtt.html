How to Use

  1. Upload XML: Select your attendance XML file and click "Process"
  2. Review Patterns: Look for recurring patterns (🔄) that can be entered as rules
  3. Manual Entry: Use individual entries for one-off attendance codes
  4. Period Mapping: Remember that periods 1,2,4,5,7 map to teaching periods 1,2,3,4,5
  5. Notes: Comments from the old system are preserved and consolidated when possible
